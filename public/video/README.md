# Home scroll tour

- cowork-tour.mp4: the cut-down walkthrough (see docs/build-plan.md, section 10.2, for the cut and the ffmpeg commands)
- cowork-tour-poster.jpg: the first frame of that cut (the WebP copy is made automatically)

After adding the clip, set the `time` of each stop in `src/lib/tour.js`. Until every stop has a
time, the tour uses the photographs instead of the video.
